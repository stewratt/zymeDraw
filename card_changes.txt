Changes to layers:

in general, we need to design a layers panel. it can be clicked and dragged to re-order layers. take design cues from photoshop and affinity and other image tools in the design. 

the added layers in the early game should allow for re-ordering their position in the layers panel. they should not be allowed for card pulls that dont directly relate to layers, like blurring or erasing etc. those actions don't necessitate layer re-ordering so they are locked in place. 



When lots of layers are added and the layers panel overflows the menu height, it covers up the "end turn" button


card specific changes:

Vignette card - remove

Draw pencil card - remove

Add option with brush for soft round brush instead of only hard round, for any card that requires a brush.

See if there are more brush types to add and add those as separate cards. affinity has all sorts of effects brushes. an HSV brush for example would be cool, or a bright/contrast brush. 

all effects should have the option to be used as brushes wherever possible. noise, blur, smudge, hsv, bright/contrast etc. it should be done as an adjustment layer, which can be re-positioned to anywhere in the layer stack.

new card : Zoom and flatten - flattens the canvas into a single layer, zooms in on the whole composition between 30-50%, and then trims the canvas to that new zoomed position.

new card - Flip canvas horizontal

new card - Remove 1 layer

new card - grid warp / liquify (procreate styel) - a more macro pulling of the canvas around like a grab tool.
